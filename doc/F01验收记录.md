# F01 实现与验收记录

日期：2026-09-18。工程实现、数据库和页面联调已通过；真实模型验收受环境条件阻塞，F01 尚未完整验收通过。

## 实现范围

- 单模块 Spring Boot 后端、按业务域分包、最小安全配置和只返回状态的 `/api/health`。
- Vue / TypeScript 启动状态页、相对 API 请求、同源开发代理、失败反馈和重试。
- Ollama / DashScope 的 Chat 与 Embedding 独立选择、统一 ChatClient、1024 维向量校验。
- PostgreSQL + pgvector 开发 Compose、Flyway 扩展迁移，以及仅在隔离测试中创建的向量表。
- 普通测试、真实数据库测试和显式真实模型测试；后续登录、知识库、RAG、Agent 业务尚未实现。

## 必要配置与操作

启动与完整检查命令见 [README](../README.md#本机启动f01)。普通启动需要数据库密码，但本地模型模式不需要云端密钥；真实模型验收额外需要已启动的 Ollama 及模型，或北京地域 DashScope 密钥。

本地模型默认 `qwen2.5:3b`、`bge-m3`；云端默认 `qwen-plus`、`text-embedding-v4 / 1024`。模型名称、地域、镜像和依赖实际值应随验证结果保存。测试只使用固定合成文本，不使用用户资料；日志和报告不记录密钥。

## 固定版本与复现记录

后端使用 Spring Boot 3.5.8、Spring AI 1.1.2、Spring AI Alibaba / Extensions 1.1.2.2。前端固定 Vue 3.5.43、TypeScript 5.9.3、Vite 8.3.0、Element Plus 2.14.5、Vitest 5.0.1，交付中包含 `package-lock.json`。

本次已执行 README 中列出的编译、普通测试、依赖树、`-Pdb-it verify`、两种 profile 的 `-Plive-ai verify`，以及前端 `ci`、`test -- --run`、`build`。两个真实模型命令均以失败退出，未将失败或缺失环境计为通过。普通测试在两种 live profile 下均通过，且不调用外部模型。

测试报告位于 `backend/target/surefire-reports/` 和 `backend/target/failsafe-reports/`。两次真实模型失败报告另保存在本机忽略目录 `.local/evidence/ollama/`、`.local/evidence/dashscope/`；后端实际启动日志位于 `.local/evidence/app-stdout.log`。报告属于可重新生成的本机构建产物，不提交。

完成剩余验收需：启动本机 Ollama 并准备 `qwen2.5:3b`、`bge-m3`；通过环境变量注入北京地域 `DASHSCOPE_API_KEY`；在 Docker 运行时分别重跑两条真实模型检查命令。测试使用隔离数据库，单项默认最长 180 秒。更换 Embedding 模型必须重建索引。
