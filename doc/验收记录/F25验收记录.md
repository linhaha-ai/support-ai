# F25 验收记录：查询真实模拟工单状态

日期：2026-09-23

结论：**F25 的工单表、30 条模拟数据、实时只读查询、成员授权、统一不可见响应和工单卡片已实现，并通过单元、安全、前端及隔离 PostgreSQL 验证；由于 F24 前置任务尚未通过验收，且认证后的完整 OpenAPI JSON 仍存在既有 springdoc 500 基线，F25 保持未勾选。**

## 本阶段实现

- 新增 Flyway V12 `ticket` 表，包含唯一外部编号、四种状态检查、知识库非级联外键、`(kb_id,status,updated_at DESC)` 索引以及表和全部字段的中文注释。
- 新增独立 `db/seed/assistant/init_ticket.sql`。脚本在演示账号种子之后执行，幂等创建独立知识库、`support1` WRITE、`support2` READ 和 `T10086`—`T10115` 共 30 条工单；重放不覆盖已有成员权限或工单状态。`admin` 仅作为负责人，不自动成为成员。
- 在 `data.assistant` 增加 `Ticket`、`TicketStatusEnum`、`TicketMapper` 和 `TicketRepository`，显式映射 UUID、枚举与带时区时间。
- `TicketQueryService` 对编号做裁剪、大写规范化和白名单格式校验，每次直接读取当前业务行，再复用 `AccessPolicy.requireRead` 检查所属 ACTIVE 知识库和当前成员关系。
- 新增 `GET /api/tickets/{ticketNo}`。接口返回业务编号、标题、说明、状态、处理人、所属知识库、状态更新时间与查询时间，不经过 Chat/Embedding/Rerank，也不提供创建、修改或关闭工单的入口。
- 工单不存在、知识库停用和没有成员权限均返回相同的 HTTP 404、`RESOURCE_NOT_FOUND` 和脱敏提示；管理员角色或知识库负责人身份不能绕过成员授权。
- Vue 工作区增加工单查询导航、加载态、统一错误与重试、严格响应结构校验和响应式工单卡片。旧请求在页面卸载时取消，不缓存旧工单状态。
