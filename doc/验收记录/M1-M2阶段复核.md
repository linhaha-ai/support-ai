## 二、阻断完成勾选的问题

1. 本机 `127.0.0.1:11434` 当前拒绝连接，Ollama Chat、流式输出、1024 维 Embedding 和相似检索没有成功记录。
2. 当前验收会话未提供 DashScope/AI 相关环境变量，DashScope 的真实 Chat、流式输出、Embedding 和相似检索没有成功记录。
3. 九模块迁移后的 Maven 编译、普通测试、依赖树和 `db-it` 尚未执行，测试源码不能代替测试运行结果。
4. 未登录访问 `/v3/api-docs` 返回 401，保护边界符合预期；但登录后访问该端点实测返回 500，OpenAPI JSON 契约尚未通过运行验收。
5. 当前开发库中 `document`、`document_version`、`ingestion_job`、`document_chunk` 和 `vector_store` 均为 0 行，没有完成 M2 要求的成功资料与故意失败资料场景。
6. M1 的创建知识库、两用户隔离、改权和撤权贯穿场景，以及 M2 的上传、租约处理、解析、向量发布、原文与分块检查完整场景尚未执行。

## 四、剩余验收命令

按照仓库约定，本轮未直接运行 Maven。需要依次取得以下命令的成功结果：

```powershell
mvn -f backend/pom.xml -DskipTests clean compile
mvn -f backend/pom.xml clean test
mvn -f backend/pom.xml dependency:tree
mvn -f backend/pom.xml -Pdb-it verify
mvn -f backend/pom.xml -Plive-ai -Dspring.profiles.active=ollama verify
mvn -f backend/pom.xml -Plive-ai -Dspring.profiles.active=dashscope verify
```

随后启动通过上述构建产生的 bootstrap 应用，完成 M1 三账号授权贯穿场景，以及 M2 一份成功资料、一份故意失败资料的完整处理与查看场景。全部结果通过后，才能同步勾选 F01—F09、M1 和 M2。
