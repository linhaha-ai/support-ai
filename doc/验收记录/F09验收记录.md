## 一、范围与结论

F09 负责让已授权知识库成员检查文档、版本、原文和分块结果。本阶段只实现读取能力，不实现新版本上传、文档删除、任务重试/取消或授权向量检索。

本阶段已实现：

- `GET /api/knowledge-bases/{kbId}/documents`：按最近更新时间返回文档、active/pending 版本和安全任务摘要。
- `GET /api/documents/{documentId}`：返回文档详情、知识库归属、版本状态和 revision。
- `GET /api/documents/{documentId}/versions`：按版本号倒序进行不透明游标分页，默认 20 条、最多 100 条。
- `GET /api/documents/{documentId}/versions/{versionId}/content`：经授权和归属校验后，从受控存储读取并校验原文。
- `GET /api/documents/{documentId}/versions/{versionId}/chunks`：按分块序号正序进行不透明游标分页，默认 50 条、最多 100 条。
- Vue 文档检查页：展示列表、详情、版本、原文、分块、任务阶段和脱敏失败信息，并覆盖加载、空数据、错误重试及快速切换场景。

## 二、安全与数据边界

- 文档和版本 SQL 同时检查启用账号、ACTIVE 知识库、成员关系和未删除文档；指定版本还要求 `document_id + version_id` 同时匹配。
- READ 与 WRITE 成员均可查看；ADMIN 角色没有成员关系时不会绕过资料读取授权。
- 原文只通过 `FileStore` 打开服务端存储键，并复核记录大小、实际字节数、SHA-256 和严格 UTF-8。
- API 不返回 `storageKey`、真实磁盘路径、配置快照、租约 owner/token 或内部错误详情。
- `document_chunk` 只保存定位元数据；正文继续以 `vector_store.content` 为唯一权威副本。`LEFT JOIN` 允许尚未完成 EMBED 的分块返回空正文，而不是伪造可用内容。
- 任务摘要复用统一脱敏规则，只返回公开状态、阶段、进度、可重试/可取消标识和安全错误信息。

## 四、待执行验收

按照项目约定，本轮未直接运行 Maven。请执行：

```powershell
mvn -f backend/pom.xml -DskipTests compile
mvn -f backend/pom.xml test
mvn -f backend/pom.xml -Pdb-it verify
```

运行验收还需启动 PostgreSQL 和应用，并准备一个 READ 成员、一个库外用户以及一个没有该库成员关系的 ADMIN。上传一份多章节 UTF-8 Markdown/TXT 后逐项确认：

1. READ 成员可以依次打开文档列表、详情、历史版本、原文和分块。
2. 库外用户、撤权用户和无成员权 ADMIN 得不到资料内容；停用知识库、已删除文档和错配 versionId 同样不可见。
3. pending 版本明确显示处理中或失败，不能标记为 active；历史版本仍能标明不是当前版本。
4. 原文不包含服务端路径或存储键；分块章节、偏移、字符数、token 数与正文可核对。
5. 空知识库、未生成分块、任务失败和接口暂时不可达时，页面分别显示清晰空态或重试入口。
6. 浏览器快速切换文档和版本时，旧请求结果不能覆盖当前选择。
