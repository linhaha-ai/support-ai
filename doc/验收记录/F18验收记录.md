# F18 验收记录：发布文档新版本并保留历史来源

日期：2026-09-22

结论：**F18 的代码、自动化测试和文档契约已落位；前端 74 项测试与生产构建通过，后端 Maven、Testcontainers、真实 API 和浏览器版本切换场景未执行，开发计划保持未勾选。**

## 实现范围

- 新增 `POST /api/documents/{documentId}/versions`，接收 UTF-8 Markdown/TXT 文件和必填 `expectedRevision`；WRITE 成员可调用，READ 成员不能更新。
- 接口在事务内锁定 document 行并重新校验当前账号、ACTIVE 知识库、成员 WRITE 权限、revision 与空 pending，避免只依赖前端状态判断。
- 不可复用时使用锁内读取的 `next_version_no` 创建 QUEUED 版本和 PARSE 任务，再以 revision、版本号及空 pending 为条件原子登记指针，同时递增 `next_version_no` 和 revision；active 指针保持不变。
- 内容与当前 active 版本相同且解析器、分块器、Embedding 模型、1024 维和配置摘要均一致时，仅在 active 为 READY、任务为 SUCCEEDED 时复用；返回 200、`reused=true`，不写文件、不创建版本或任务，也不重复调用 Embedding。
- 普通更新返回 202、`reused=false`，后续复用 F06—F08 的持久任务、租约处理和 READY/active/SUCCEEDED 原子发布。事务登记失败时删除本次新文件，不删除旧 active 或历史版本文件。
- 旧版原文件、正文、分块和向量在 F18 更新中保留。现有来源预览按 active 指针返回 `isCurrent`；授权检索、来源登记和 F16 历史选择继续限定 active/READY，旧版回答不能作为当前事实重新注入。
- 文档详情页仅向 WRITE 成员显示上传入口，存在 pending 时禁用；页面携带当前 revision，兼容 200 复用与 202 排队，并复用已有任务轮询和错误展示。
- F18 复用 V6 文档版本结构和 V11 来源结构，不新增 Flyway 迁移。

## 关键状态流

```text
读取文档详情 revision
  → 校验 WRITE 权限、文件和处理配置
  → 锁定 document 并复核 revision/pending/权限
  → 当前 READY + SUCCEEDED 版本内容和配置相同
      → 200 reused=true，不产生写入
  → 否则写入受控文件
      → 再次锁定并复核 revision/pending/权限
      → 创建递增版本号与 QUEUED/PARSE 任务
      → 原子登记 pending，active 保持旧版本
      → 202 reused=false
  → 完整解析、分块、Embedding 与发布成功
      → READY + active 切换 + pending 清空 + SUCCEEDED
```

两次事务复核之间若发生并发更新，后一次登记返回 409，并补偿删除刚写入但未登记的文件。

## 自动化测试契约

后端测试已经覆盖或声明以下场景，只有实际运行后才能计为通过：

| 场景 | 预期结果 |
| --- | --- |
| 当前版本复用 | 返回 200、SUCCEEDED、`reused=true`；文件、版本、任务数量和 revision 不变 |
| 新版受理 | 返回 202、QUEUED、`reused=false`；版本号递增，pending 指向新版，active 仍指向旧版 |
| stale revision | 返回 409 `DOCUMENT_VERSION_CONFLICT`，数据库和文件不变 |
| 已有 pending | 第二次更新返回 409，不分配额外版本号或任务 |
| 同 revision 并发 | 两个线程经同步栅栏同时提交不同文件，仅一个 202、一个 409，只保留一个新版、任务、pending 和新文件 |
| 缺少 revision | 返回 400 `INVALID_REQUEST`，不进入文件存储 |
| READ 成员 | 返回 403，文件不落盘 |
| 提交失败 | 新版事务回滚并删除本次文件，旧 active、revision 和历史版本不变 |
| OpenAPI | POST multipart 包含 file、expectedRevision 和 CSRF，200/202 均声明响应模型 |
