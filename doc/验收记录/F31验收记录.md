## 实现范围

- 新增 `deploy/compose.yml`，统一部署 Nginx web、Spring Boot app、PostgreSQL 16 + pgvector，以及仅在维护 profile 启动的一次性 maintenance 容器。
- app/web 使用多阶段 Dockerfile 并锁定基础镜像摘要；app 以非 root 用户运行，原文件写入独立命名卷，数据库使用另一命名卷。
- Nginx 同源代理 `/api`、`/v3/api-docs` 和 `/doc.html`；SSE 路径关闭代理缓冲、响应缓存和 `X-Accel-Buffering`，读取超时与后端执行上限匹配。
- 新增 `.env.example`，数据库密码必须由本地忽略的环境文件提供；Cookie Secure 开关、监听地址、HTTP 端口和 Ollama 地址均可外部覆盖。
- 备份脚本在停止 app 写入后导出 PostgreSQL custom archive 和原文件 tar，生成固定格式 `MANIFEST` 与 `SHA256SUMS`，成功后才重新启动 app/web。
- 恢复脚本拒绝未知文件、非法归档路径和摘要不一致；先恢复临时数据库，核对 Flyway 版本、未删除文档的存储键/大小/摘要及 active/pending 指针，再恢复目标数据库与原文件。失败时不自动把应用恢复到可写状态。
- 新增确定性 Ollama 协议桩和端到端 PowerShell 验收脚本。协议桩提供 1024 维 Embedding、查询改写和三段流式回答，只用于部署链路验收。
