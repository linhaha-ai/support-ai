实现提交为 `2d929cd5038b349ef2b82328df2fcad2e06ddc22`。最终归档包括 [VECTOR 开发集](../../evaluation/results/f32-development-vector.json)、[FUSION 开发集](../../evaluation/results/f32-development-fusion.json)、[策略比较](../../evaluation/results/f32-strategy-comparison.json) 和 [DEV-042 独立提供方复测](../../evaluation/results/f32-fusion-provider-recheck.json)。VECTOR 采集时间为 2026-09-29 14:48:33—14:50:42 UTC，FUSION 为 14:52:50—14:55:51 UTC。

## 一、取舍结果与口径

本轮**保留 VECTOR 作为冻结策略**。FUSION 没有改善 DEV-002、013、033 的关键事实缺口，两道变化题也没有新增预期事实命中；辅助阅读出现局部改善与局部回退，未形成足以替换基线的可靠质量收益。人工质量门槛仍未完成，不能将本次冻结或开发集比较称作质量验收通过。DEV-042 的提供方故障不作为选择 VECTOR 的策略退化理由。

VECTOR 完成 48 次真实问答，12 个特殊场景为 `NOT_RUN`；40 道可回答题中，37 道完整命中预期事实的入模证据，缺口为 DEV-002、013、033。这是**应用分数和 Token 预算筛选后的实际入模证据命中**，不是原始候选召回率，也不是答案正确率。

| 指标 | VECTOR | FUSION |

比较器已要求同一镜像、非策略环境、源码、执行器、语料及除 `retrieval.strategy` 外的配置一致。原始 `retrievalRegressions=[DEV-042]` 来自该题未完成，不代表 FUSION 丢失了预期证据：失败记录中仍有 `PAY-CB-V2-OBSERVABILITY`。排除这道故障题，两策略在共同可比较的 39 道可回答题中均为 36 道完整入模命中，没有预期事实新增或丢失。

另对两边均 `COMPLETED` 的相同 47 道普通问答作辅助配对统计（不覆盖原报告）：VECTOR/FUSION 的已知 Chat Token 合计分别为 **40,667 / 41,156**，总时延 p50 为 **1,465 / 2,029 ms**，p95 为 **4,243 / 8,379 ms**。两批次各只执行一次，模型生成长度与运行波动会影响时延，不能将这些差值当成策略稳定因果效应；其作用是说明本轮没有观察到抵消额外代价的召回收益。

统计限制：归档时修正了原汇总遗漏生成失败前 Embedding 调用的问题，FUSION 的 `embedding.attemptedRuns` 现为 48，包含 DEV-042 这次“检索已成功，随后 Chat 500”的调用；实际 48 道普通题均已完成查询向量检索。Embedding Token 均未知，总量保持 `null`，不能按次数估算成本。无法确认是否调用的前置失败另计 `attemptUnknownRuns`，本批为 0。汇总修正不改原始答案、失败或冻结记录。比较产物中 `PERMISSION` 分类的 4/4 也不是独立权限执行通过，12 条特殊场景仍按 `NOT_RUN` 与独立验收记录分别解释。

存在引用表达边界：DEV-030 使用“来源 [1] 至 [6]”，解析器只登记首尾两来源；DEV-031 使用 `[1-6]`，没有被识别为合法单号引用。二者均拒答了问题，但范围式引用不能代表所有来源已被系统登记。

### 冻结边界

保留 VECTOR 的依据是本轮 FUSION 没有解决关键事实缺口、没有新增预期事实命中，而人工引用与依据充分性验收尚未完成；不是认定 VECTOR 所有答案正确，也不是把一次提供方故障归因于 FUSION。DEV-002/013/033 的检索缺口、DEV-014 的答案重点错误、场景混淆和非标准引文仍作为已知质量边界保留。固定测试集应在冻结后独立执行，本页不读取其题目或参与针对固定题调参。
