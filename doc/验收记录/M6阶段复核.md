## 关键边界核对

| 边界 | 当前实现及验证 | 保留限制 |
| --- | --- | --- |
| 只读工具与身份 | 仅两个服务端固定工具；模型参数只有 query/ticketNo，不能替换用户、会话或增加工具 | 未以真实模型执行完整恶意指令样本 |
| 固定会话范围 | 即使用户在其他知识库有读取权，会话范围外的工单仍不可查 | 真实 HTTP 及运行中撤权仍需串联验证 |
| 当前工单状态 | 本轮真实查询，答案必须引用目标工单的本轮直接来源 | 自然语言意图为有限规则，复杂指代仍需真实样本验收 |
| 历史查询结果 | 继承直接指向历史根来源，保留原工具调用 ID 和查询时间；页面区分先前/本轮结果 | `isCurrent` 只表示该回答本轮查询，不保证展示时仍实时 |
| 完整来源校验 | 未引用但入模的文档也属于来源闭包；替换、删除、撤权后整轮排除或运行失败 | 完整浏览器交互和真实模型时序未验证 |
| 执行预算 | 默认 2 次工具、3 次模型、8000 Token 上下文、20 秒单工具与 60 秒总执行时间 | 超出默认组合预算时按失败收口，不承诺任意多工单组合 |
| 历史预算 | 默认 3 轮、6000 字符的问答与来源快照预算；单次历史数据注入 | 总 Prompt 仍受完整 Token 预算约束 |
| 错误收口 | 模型/工具错误和参数解析失败保留首次失败；未完成的工具消息不能当作最终成功答案；测试装配已修复 | 真实模型和工具故障仍需端到端验证 |

多轮数据库测试确认：第一轮得到 OPEN，外部更新为 RESOLVED；第二轮问先前结果，保留 OPEN 且没有新调用；第三轮“现在呢”产生新调用并返回 RESOLVED。继承仍追溯第一轮根记录；撤权后模型不再得到旧结果，历史内容与来源对用户不可读；跨用户/跨会话根来源被拒绝，混合合法/非法继承批次整批回滚。
