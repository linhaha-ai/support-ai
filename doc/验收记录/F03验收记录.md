## 四、建议验收命令

在仓库根目录执行：

```powershell
mvn -f backend/pom.xml -DskipTests clean compile
mvn -f backend/pom.xml clean test
mvn -f backend/pom.xml -Pdb-it verify

npm --prefix frontend run test -- --run
npm --prefix frontend run build
```

Maven 通过后启动 bootstrap，使用 `admin/admin` 登录，按以下顺序手工回归：管理员创建知识库、普通用户越权创建失败、已授权成员可查看知识库详情、无成员用户返回 404、停用后普通列表隐藏、管理员管理列表仍可见、旧 revision 更新返回 409、按新 revision 恢复后仅成员重新可见。
