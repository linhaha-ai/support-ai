# F32 接口、数据关系与阶段证据覆盖矩阵

盘点日期：2026-09-29。来源为当前 Controller、V1—V15 生产迁移、JUnit 测试源码和既有验收记录。

本文件记录**可执行证据与断言的对应关系**，不把“找到测试源码”写成“本轮测试通过”。本轮运行时间、结果、模型评测和业务回放以 [F32 验收记录](F32验收记录.md) 为准；历史阶段数字不累计为本轮结果。

## 一、统计口径与证据等级

- 35 个业务操作按 `HTTP method + path` 计数，来自 [Controller 目录](../../backend/support-ai-bootstrap/src/main/java/com/haha/supportai/controller)。同路径不同方法分别计数，不含健康检查、Knife4j 页面和 `/v3/api-docs`。
- 16 张业务表按 [生产迁移目录](../../backend/support-ai-bootstrap/src/main/resources/db/migration) 的 `CREATE TABLE` 计数，不含 `flyway_schema_history`、真实模型测试专用表和 PostgreSQL 系统表。
- **HTTP+DB**：MockMvc 调用真实控制器、业务服务和 Testcontainers PostgreSQL；不代表部署端口上的浏览器场景。
- **HTTP 替代**：MockMvc 保留认证/路由/响应契约，但业务服务或仓库使用替代对象；不代表真实 SQL 或模型执行。
- **服务+DB / 单元**：验证生产服务事务或 Mapper / 验证隔离业务逻辑。它们补充 HTTP 契约，不能独自证明完整外部请求链路。
- `类名:行号` 指测试方法起始位置，后列给出语义断言；后续行号变化以方法名和断言为准。

## 六、完整回归命令与边界

仓库根目录使用 JDK 21、Docker 可用时，普通测试与全部生产数据库集成的最短单命令：

```powershell
mvn -B -ntp -f backend/pom.xml -Pdb-it '-Dit.test=*DatabaseIT,FlywayMigrationCompatibilityIT' verify
```

`verify` 先跑 Surefire 普通测试，再跑 Failsafe 数据库集成。当前 18 个 `*DatabaseIT` 类加 1 个 `FlywayMigrationCompatibilityIT`，合计 19 类；`db-it` 默认只包含前者，必须显式加入迁移兼容测试。此命令没有跳过普通测试，也未用 `-Dtest` 缩窄范围；不调用真实模型。

本地真实 Chat/Embedding/PgVectorStore 接入独立执行：

```powershell
mvn -B -ntp -f backend/pom.xml -Plive-ai '-Dit.test=ProviderLiveAiIT' verify
```

接入测试不能替代 60 题开发比较、40 题固定集和真实助手业务。实际 Maven/JDK 路径、仓库参数、执行时间与计数在 F32 验收记录保留。
