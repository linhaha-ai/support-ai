- [RagAnswerServiceTest](../../backend/support-ai-conversation/src/test/java/com/haha/supportai/conversation/service/rag/RagAnswerServiceTest.java):406 `marksOnlyRegisteredCitationsAndRetainsUncitedModelInputs`，替代 `ChatModelGateway` 输出包含 `[99]`，断言两条入模来源登记、完成时引用号仅为 `List.of(2)`，正文中的 `[99]` 保留为普通文字。
- [ChatSessionView.test.ts](../../frontend/src/__tests__/ChatSessionView.test.ts):280 新增“未登记引用 [99] 保留为正文，不生成可点击来源且不改变已登记来源”，实际挂载组件并送入 SSE `delta/sources/done`；断言 `[99]` 留在正文、无对应来源按钮，合法来源的定位及预览仍一致。

### E02：引用去重与数据库唯一性

- [CitationParserTest](../../backend/support-ai-conversation/src/test/java/com/haha/supportai/conversation/support/CitationParserTest.java):12 `keepsRegisteredCitationsInFirstOccurrenceOrderWithoutDuplicates`，输入 `[2]...[1]...[2]` 只返回 `[2,1]`。
- [ChatConversationDatabaseIT](../../backend/support-ai-bootstrap/src/test/java/com/haha/supportai/conversation/ChatConversationDatabaseIT.java):96 `enforcesDocumentSourceCitationTypeAndJsonConstraints`，首次插入成功、再次插入同 message/citation_no 抛数据库异常，同时检查默认 `is_cited=false`。
- [ChatSessionView.test.ts](../../frontend/src/__tests__/ChatSessionView.test.ts):314 新增“正文重复引用 [1][1] 时仅显示一个已登记来源入口，点击只请求该分块一次”，由 SSE 夹具输出题面字面正文并检查唯一按钮、预览及唯一 GET；包含在上面的 10/10 中，不另行累加。
- 解析器去重、数据库拒绝重复记录与页面去重分别有证据；数据库“拒绝重复插入”不是服务“不会尝试重复插入”的证明，仍未形成同一替代模型输出贯穿真实落库与部署页面的单条场景。

### E03：他人私有资料隔离与零证据分支

- [AuthorizedRetrievalDatabaseIT](../../backend/support-ai-bootstrap/src/test/java/com/haha/supportai/knowledge/retrieval/AuthorizedRetrievalDatabaseIT.java):61 `filtersAuthorizationAndPublicationStateBeforeVectorTopK`，真实 PostgreSQL 中高相似资料也必须满足用户、会话范围、发布状态；库外身份或他人会话不返回片段。
- [CrossFeatureAuthorizationDatabaseIT](../../backend/support-ai-bootstrap/src/test/java/com/haha/supportai/acceptance/CrossFeatureAuthorizationDatabaseIT.java):121 `authorizationChangesStayConsistentAcrossDocumentsConversationsAndTools`，分别切换 otherUser 与无成员 administrator，调用 `assertForeignIdentityCannotRead`（257 行）验证资料/检索/会话/运行/工具隔离。
- [RagAnswerServiceTest](../../backend/support-ai-conversation/src/test/java/com/haha/supportai/conversation/service/rag/RagAnswerServiceTest.java):172 `completesWithExplicitInsufficientInformationWithoutCallingModelWhenNoEvidenceExists`，检索为空时保存明确资料不足、无引用、模型和来源登记不调用。
- 本轮新增独立权限脚本补齐 DEV-017/037 的真实 HTTP/数据库场景：分别新建会话，只固定 support1 新库，提问 support2 支付新库中随机合成的私有事实；校验所有入模来源的 `kb_id` 均属于本人库、HTTP/SSE/历史及数据库正文均没有私有值，并明确资料不足。真实标识见第三节。

### E04：管理员仍须成员权才能建立资料会话

- [AccessPolicyTest](../../backend/support-ai-bootstrap/src/test/java/com/haha/supportai/knowledge/access/AccessPolicyTest.java):109 `administratorWithoutMembershipCannotDiscoverDataResource`，管理员身份不能绕过资料读取成员检查；120 行相邻测试仅允许无成员管理员管理元数据。
- [ChatSessionServiceTest](../../backend/support-ai-conversation/src/test/java/com/haha/supportai/conversation/service/session/ChatSessionServiceTest.java):133 `rejectsKnowledgeBaseOutsideCurrentUsersReadableScope`，固定范围不可读时抛 `ChatSessionKnowledgeBaseUnavailableException`，会话仓库及会话范围仓库无交互。
- [CrossFeatureAuthorizationDatabaseIT](../../backend/support-ai-bootstrap/src/test/java/com/haha/supportai/acceptance/CrossFeatureAuthorizationDatabaseIT.java):121 以真实管理员夹具检验资料/历史/检索隔离；它未调用“无成员管理员新建该库会话”的 HTTP 路径。
- 本轮独立权限脚本已补齐 DEV-018/038：只撤销 admin 在本轮新建支付库上的自动成员关系，保留 admin 管理角色；两次 POST 会话均拒绝，分别对照执行前后的管理员总会话、总运行及目标库范围计数，均无新增。

### E05：检索后撤权的复核与来源登记

- [RagAnswerServiceTest](../../backend/support-ai-conversation/src/test/java/com/haha/supportai/conversation/service/rag/RagAnswerServiceTest.java):302 `revalidatesEvidenceAndRegistersEveryModelInputBeforeCallingModel`，首次检索两条、复核剩一条，只登记剩余条目且登记先于模型调用。
- [AuthorizedRetrievalDatabaseIT](../../backend/support-ai-bootstrap/src/test/java/com/haha/supportai/knowledge/retrieval/AuthorizedRetrievalDatabaseIT.java):178 `revalidatesOnlyCurrentEvidenceButAllowsAuthorizedHistoricalSourcePreview`，实际删除成员关系后复核为空、来源不可读。
- [ChatConversationMapperDatabaseIT](../../backend/support-ai-bootstrap/src/test/java/com/haha/supportai/conversation/ChatConversationMapperDatabaseIT.java):292 `rejectsWholeEvidenceBatchAfterProductionRunClaimWhenAnySourceIsOutsideSessionScope`，生产 run 领取后，越界混合来源批次整体回滚；实际删成员后再次登记合法来源也失败，两次均核对来源表为空。
- [RagAnswerServiceTest](../../backend/support-ai-conversation/src/test/java/com/haha/supportai/conversation/service/rag/RagAnswerServiceTest.java):448 `doesNotCallModelWhenEvidenceRegistrationFails`，登记失败不调用模型；463 `doesNotCallModelWhenSourceIsRevokedImmediatelyAfterRegistration` 覆盖登记后的再次复核失败，保存 `SOURCE_REVOKED`，不调用模型。
- 463 行发生在**已登记来源之后**，不可用来证明“不新增来源”。本题需要检索后、登记前撤权；已有分层证据覆盖对应规则，但没有题号绑定的端到端暂停点记录。

### E06：历史版本可预览，但仍受当前授权和删除状态约束

- [AuthorizedRetrievalDatabaseIT](../../backend/support-ai-bootstrap/src/test/java/com/haha/supportai/knowledge/retrieval/AuthorizedRetrievalDatabaseIT.java):178，历史版本不作为当前检索证据，但授权预览正文存在且 `isCurrent=false`；成员撤销后来源查询为空。
- [DocumentSourceQueryServiceTest](../../backend/support-ai-knowledge/src/test/java/com/haha/supportai/knowledge/service/source/DocumentSourceQueryServiceTest.java):39 `returnsAuthorizedHistoricalReadySourceWithCurrentMarker` 保留历史定位和正文并标旧；77 `keepsDeletedSourceMetadataForAuthorizedHistoryButHidesPreview` 保留历史元数据、标 `available=false`/`isCurrent=false`，正文预览抛不存在。
- [CrossFeatureAuthorizationDatabaseIT](../../backend/support-ai-bootstrap/src/test/java/com/haha/supportai/acceptance/CrossFeatureAuthorizationDatabaseIT.java):121，在撤权及停用库后分别调用 `assertOwnerContentIsHidden`/`assertDirectEntriesHidden`，正文与来源读取均受限；这里用的是当前已发布文档，不是同一旧引用的完整多分支回放。
- 业务脚本确实上传新版后检查旧 chunk 的 `isCurrent=false`，撤权后再次请求该旧 chunk 并拒绝；删除场景使用另一份独立文档，不能补齐“删除历史引用所属文档后拒绝”的题意，也未设置知识库停用分支。
