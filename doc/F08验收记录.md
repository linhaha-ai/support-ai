## 一、范围与结论

F08 负责把 F07 的稳定分块转换为 1024 维文档向量，并且只在全部分块、向量、模型配置和任务租约一致时发布版本。本阶段不增加匿名模型接口，不实现 F09 的文档查看接口，也不实现 F11 的授权检索入口。

本阶段已实现的代码能力包括：

- 使用 Flyway V9 创建 `id/content/metadata/embedding` 四字段 `vector_store`，`id` 一对一引用 `document_chunk.id`，向量固定为 `vector(1024)`。
- 通过 `VectorTypeHandler` 和 MyBatis 显式批量 SQL 写入已生成向量，不调用会再次触发 Embedding 的 `VectorStore.add()`；初期保留精确检索基线，不提前创建 HNSW。
- EMBED 在事务外按 `support.ai.document.embedding.batch-size` 调用唯一 `EmbeddingModel`，校验返回数量、输入顺序、1024 维和有限浮点数。
- 每次执行重新受控读取原文件，按固化配置重新分块，并与 `document_chunk` 的 ID、序号、章节、偏移、摘要和计数逐项核对。
- 重试时只接受 ID、正文和 metadata 均一致的连续已完成前缀；该前缀不重复调用模型，后续批次继续生成。
- 每批模型调用前校验有效 EMBED 租约；模型返回后在短事务中再次锁定并复核 job、version、document、owner、token、有效期、pending 和删除状态，幂等确认 chunk、写入 vector、核对数量并更新进度。
- PUBLISH 再次校验当前 Embedding 提供方、模型、维度和配置快照；同一事务内核对块数、向量数和有效维度数，完成版本 READY、active 切换、pending 清理和任务 SUCCEEDED。
- Worker 已注册 PARSE、CHUNK、EMBED、PUBLISH 四个唯一处理器；发布处理器返回终态结果，不再调用普通阶段推进 SQL。

## 三、待执行验收

按照项目约定，本轮未直接运行 Maven。当前开发库核验不能替代空库迁移、重复启动、Mapper 和事务测试；以下命令须由用户执行并返回结果后，才能把对应项记为通过：

```powershell
mvn -f backend/pom.xml -DskipTests compile
mvn -f backend/pom.xml test
mvn -f backend/pom.xml dependency:tree
mvn -f backend/pom.xml -Pdb-it verify
mvn -f backend/pom.xml -Plive-ai -Dspring.profiles.active=ollama verify
mvn -f backend/pom.xml -Plive-ai -Dspring.profiles.active=dashscope verify
```

成功判据：

| 验收层 | 必须确认的结果 |
| --- | --- |
| 编译与单元测试 | 新增类、MyBatis 注解、Spring AI 1.1.2 `EmbeddingModel` API 和全部单元测试通过 |
| 数据库迁移 | 当前开发库已确认 V1—V9 与四字段 `vector(1024)`；仍需空库顺序执行、重复启动及非 1024 维拒绝测试 |
| 批次幂等 | 同一批重复提交不增加记录；已完成连续前缀重试不重复调用模型 |
| 租约隔离 | 错误 owner/token、过期租约、删除文档或失效 pending 均不能写 vector 或发布 |
| 中途失败 | 已提交批次可以保留供续作，但版本仍为 BUILDING，active 不切换，任务不能 SUCCEEDED |
| 发布原子性 | READY、active 指针、pending 清空、任务 SUCCEEDED 同时可见；最后一步失败时全部回滚 |
| 真实模型 | Ollama `bge-m3` 与 DashScope `text-embedding-v4` 分别返回 1024 维有限向量；Chat/流式前置验收仍按 F01 记录执行 |

完整应用验收还需启动 PostgreSQL、准备对应模型和凭据，上传一份多分块 Markdown/TXT，轮询 `GET /api/ingestion-jobs/{jobId}` 直到 `SUCCEEDED/PUBLISH`，再核对：

- `document_version.status = 'READY'`；
- `document.active_version_id` 指向该版本且 `pending_version_id IS NULL`；
- `document_chunk`、`vector_store`、`vector_dims(embedding)=1024` 三个数量与版本 `chunk_count` 完全一致；
- 日志、任务错误和接口响应不包含密钥、供应商原始响应或本机绝对路径。
